# Richmond Park Schools Sarajevo — TV Digital Signage (Light Mode)

An HTML-based school digital signage application for TV displays that shows the **Current Lesson (Now)** and **Next Lesson (Up Next)** in real time in **English & Bosnian** (with English track badges), combined with a full-stage **Media Slideshow (Images & Videos)** and a built-in **Hidden Timetable Editor**.

---

## 📁 Folder Structure

```text
school-slide-show/
├── index.html               # Main TV application page (open in a browser on the TV)
├── config.js                # Slide duration settings, Friday season (winter/summer) & editor PIN
├── styles.css               # Light Mode 16:9 TV layout styles
├── app.js                   # Live clock, bell schedule sync, bilingual dictionaries & slideshow engine
├── editor.js                # Built-in hidden timetable & class editor (English UI)
├── editor.css               # Styles for the hidden timetable editor
├── start-tv.bat             # Double-click to auto-sync media/JSON and launch the TV display
├── sync-media.bat           # Double-click after adding/removing photos/videos or updating JSON files
├── sync-data.ps1            # PowerShell script that scans media/ and regenerates fallback-data.js
├── data/                    # JSON data directory
│   ├── timetable.json       # Master class schedules (Grades 1–4, tracks, homeroom teachers & split groups)
│   ├── bell_schedule.json   # School bell schedules (Mon–Thu, Friday Winter, Friday Summer)
│   ├── media.json           # Media playlist (auto-generated by sync-media.bat)
│   └── fallback-data.js     # Auto-generated JS bundle so index.html works directly via file://
└── media/                   # Drop images (.jpg, .jpeg, .png, .svg, .webp, .gif) & videos (.mp4, .webm) here
    ├── announcements-poster.svg
    ├── Default-social-share-image-sarajevo.jpg
    └── welcome-poster.svg
```

## ⚙️ Key Features & Usage Guide

### 1. Running the Application on the TV
- Double-click **`start-tv.bat`** (or open **`index.html`** directly in Google Chrome / Microsoft Edge and press **F11** for Fullscreen mode).
- `start-tv.bat` automatically syncs the `media/` folder and JSON files before opening the display.

### 2. Adding or Removing Images / Videos (`media/`)
1. Place or remove image files (`.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`, `.gif`, `.bmp`) or video files (`.mp4`, `.webm`, `.ogg`, `.mov`, `.m4v`) inside the **`media/`** folder.
2. Double-click **`sync-media.bat`** (or re-run **`start-tv.bat`**), then refresh the TV browser.
3. The script automatically scans `media/` and updates `data/media.json` and `data/fallback-data.js`—no manual code edits required.
4. **Full-Stage Media Playback:** Whenever media slides are playing (both in between class slides and after school hours), the `top-header` and `bottom-bar` are automatically hidden so only `main-stage` is displayed.

### 3. Built-In Hidden Timetable Editor (Real-Time In-App Editing)
You can edit schedules, split groups, classes, and homeroom teachers directly inside the TV app without manually editing JSON files.

1. **Open the Editor (Secret Trigger):**
   - Click the **`RPS`** logo badge in the top-left corner **5 times quickly**, OR
   - Press **`Ctrl + Shift + E`** on the keyboard (works at any time, including during full-stage media playback).
   - *Optional PIN Protection:* Set `EDITOR_PIN` in `config.js` (e.g. `EDITOR_PIN: "1234"`) to require a PIN before opening the editor. Leave it as `""` for no PIN.
2. **Manage Classes & Homeroom Teachers (`Select a class` view):**
   - All grades (**Grade 1 – Grade 4**) are always listed.
   - **`+ Add class`**: Add a new class to any grade (automatically suggests the next available letter, e.g. `4D`, `1C`) with an empty timetable.
   - **`⚙ Edit`** (or **`⚙ Class settings`** inside a class grid): Change the **Class ID** (rename), **Grade**, **Homeroom teacher**, or **Track**.
   - **`🗑`**: Delete a class and its timetable (e.g. if a grade shrinks from `4A–4C` down to `4A–4B`).
3. **Edit Weekly Timetable Boxes:**
   - Click any class card (e.g. `4C`) to open its interactive weekly grid (**Monday–Friday × Period 1…8**).
   - Click any period box to edit **Subject**, **Group**, **Room**, and **Teacher** (with autocomplete suggestions).
   - **`+ Add group (split the class)`**: Split a period into multiple groups (e.g. `First` / `Second1` / `Second2`, `Boys` / `Girls`, `Bosnians` / `Foreigners`, `Religion` / `Culture of Religion`, or elective tracks `Math IT`, `IT`, `Social`, `Science`, `Language`). Split lessons are highlighted in yellow.
   - **`🗑 Clear lesson`**: Empty the selected period.
   - **`+ Add row`**: Add extra period rows (Period 9, etc.).
4. **Save & Persist Changes:**
   - Click **`✔ Save`** (or press `Ctrl + Enter`): The TV display updates immediately in real time and changes are saved in the browser's `localStorage`.
   - To permanently write changes to disk or copy them to another PC: click **`💾 Save to file`** (select `data/timetable.json`) or **`⬇ Export JSON`**, then run **`sync-media.bat`**.
   - Click **`↺ Reset`** to discard all in-app edits (lessons, classes, homeroom teachers) and revert to `data/timetable.json`.
   - If `data/timetable.json` is replaced with a newer export (different `school_info.last_updated`), older browser-local edits are automatically bypassed.

### 4. Editing JSON Files Directly (`data/`)
- You can also edit **`data/timetable.json`** or **`data/bell_schedule.json`** in a text editor.
- After editing any JSON file, double-click **`sync-media.bat`** so `data/fallback-data.js` stays in sync when opening `index.html` via `file://`.

### 5. Track Badges & Track Slides (English)
- Classes with track-specific lessons automatically cycle through separate slides per track (`MATH-IT`, `SOCIAL`, `SCIENCE`, `LANGUAGE`, `IT / DEV`).
- All `track-badge` labels, codes, class identity bar track names (`General Track`, `Math & IT Track`, `Social Studies Track`, `Sciences Track`, `Languages Track`, `Information Technology Track`), and timeline track tags use **English**.

### 6. Hidden Setting: Friday Bell Schedule (`winter` / `summer`)
Open **`config.js`** and set `FRIDAY_SEASON`:
```javascript
FRIDAY_SEASON: "winter", // Options: "winter" (ends 15:10) | "summer" (ends 15:20)
```

### 7. Slide Duration & School Hours Behavior
- **During Lesson Periods:** Each class/track slide is shown for **8 seconds** (`CLASS_SLIDE_DURATION_SECONDS`).
- **During Breaks (Short Break / Breakfast / Lunch):** Automatically speeds up to **6 seconds per slide** (`CLASS_SLIDE_BREAK_DURATION_SECONDS`).
- **Before Morning Start (`07:30`) / After Dismissal / Weekends:** Once the final bell rings (`15:00` Mon–Thu, `15:10` Friday Winter, `15:20` Friday Summer) or on weekends, the display automatically runs in continuous **Media Slideshow** mode.

### 8. Admin / Testing Keyboard Shortcuts
- **`T`**: Toggle the **Time Simulator Panel** at the bottom-left to test any day of the week and time of day.
- **`Right Arrow (→)`**: Manually advance to the next slide.
- **`Ctrl + Shift + E`** (or **5× click on `RPS` logo**): Open/close the **Timetable Editor**.
- **`Esc`**: Close the active modal, return to the class list, or close the Timetable Editor.
